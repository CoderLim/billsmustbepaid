## 1. 执行摘要

近 28 天：**929 点击 / 17,965 展示**，CTR ~**5.2%**，平均排名 ~**7.3**。相对 8/28 基线（818 / 16,528 / 4.9% / 7.5），28 天总量略好，但**日展示量自 8/28 后腰斩级下滑**，绝对点击同步走弱。

| 信号       | 判断                                                                   |
| ---------- | ---------------------------------------------------------------------- |
| 日展示     | 8 月中高峰 ~900–1,200/天 → 9 月初 ~180–340/天（约 **-70%**）           |
| 周环比     | 点击 **-35%**，展示 **-63%**；CTR 升到 8.2% 主要因展示塌缩，非健康增长 |
| 品牌词排名 | `bills must be paid` 近一周均位从 ~8 跌到 **~13.5**                    |
| `… game`   | 仍常进前 4，CTR 仍接近 0（0.4%），目标 2% 未达标                       |
| 攻略页     | Piggy Shuffle / Skill Tree 继续优秀（CTR 18–25%+，排名前 3）           |
| 博客介绍页 | 28 天从 0 点击 → **2 点击**，但近一周又回 0，排名恶化到 ~30            |

**核心结论：** 8/28 的 CTR 优化**尚未兑现**到品牌词/首页成功标准；当前更大风险是 **品牌可见度（展示 + 排名）下滑**。攻略长尾仍是流量支柱。问题已从「单纯标题不吸睛」扩展为「品牌 SERP 竞争 + 展示池收缩」。

### 4.4 `bills must be paid game` 异常

多日出现 **均位 1.0–2.2、展示数十次、点击 0**。对位置 1–3 的期望 CTR 约 8–25%，实际 ~0%。高度指向：

1. SERP 上摘要/标题仍不像「可玩的免费游戏站」；或
2. 被 Steam / CrazyGames / 官方站 / 视频结果抢走点击；或
3. AI Overview / 富媒体导致零点击。

**已于 2026-09-10 完成 SERP 对比** → 见 [serp-2026-09-10.md](./serp-2026-09-10.md)。

要点：US 品牌词第 1 页无本站蓝链；`… game` 均位 ~3 但快照无蓝链、疑似图/KP 展示；wiki 词第 3 且 CTR 健康。**故暂不改首页 title/H1。**
