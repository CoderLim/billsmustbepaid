## 1. 执行摘要

站点约 **2026-08-07** 起有搜索数据（新站约 3 周）。28 天内共 **818 次点击、16,528 次展示**，整体 CTR ~**4.9%**，平均排名 ~**7.5**。

| 信号     | 判断                                           |
| -------- | ---------------------------------------------- |
| 展示量   | 稳步上升（后期 ~900–1,200/天）                 |
| 点击量   | 8/15–17 峰值后回落（21–44/天）                 |
| CTR      | 近期下滑（展示涨、点击跌）                     |
| 西语市场 | `/es` 174 点击，拉美合计占比高                 |
| 攻略页   | Piggy Shuffle、Skill Tree CTR 15–25%，表现健康 |
| 品牌词   | `bills must be paid` 4,285 展示但 CTR 仅 2.05% |

**核心结论：** 排名基本稳定，主要问题是 **SERP 标题/摘要吸引力不足**（尤其首页与品牌词），而非索引或技术故障。

## 6. 复查计划

GSC 数据有约 **2–3 天延迟**；title/meta 改动通常需 **2–3 周** 才能在 CTR 上看出稳定趋势。

| 日期                    | 类型       | 检查项                                                                                                                 |
| ----------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------- |
| **2026-09-04**（+1 周） | 快速检查   | 首页、`bills must be paid game` 排名是否变化；GSC Indexing → Pages 索引量                                              |
| **2026-09-18**（+3 周） | **主复查** | 品牌词 CTR；首页 / achievements / guides 展示与 CTR；西语 `gratis` / `descargar` 查询；`/blog/what-is` 是否脱离 0% CTR |
| **2026-08-31**（月底）  | 月度快照   | 导出 Performance 全量数据；截图日趋势图；对比 8/28 基线                                                                |
| **2026-09-28**（+1 月） | 月度审计   | 完整 GSC 月度清单（Performance、Indexing、Sitemap、CWV、Enhancements）                                                 |

### 主复查（2026-09-18）成功标准

- [ ] `bills must be paid` CTR ≥ 3.5%（当前 2.05%）
- [ ] `bills must be paid game` CTR ≥ 2%（当前 0.25%）
- [ ] 首页 CTR ≥ 3.5%（当前 2.56%）
- [ ] `/blog/what-is-bills-must-be-paid` 有点击（当前 0）
- [ ] 周点击不再持续低于 8/15–17 峰值水平，或能解释季节性/竞争原因

### 若 CTR 仍低

1. 对比 SERP 截图（Steam、CrazyGames、官方站是否抢占摘要）
2. 微调首页 title 前 40 字符（Google 截断点）
3. 考虑为首页添加 Review / VideoGame schema（需有可靠评分来源）
