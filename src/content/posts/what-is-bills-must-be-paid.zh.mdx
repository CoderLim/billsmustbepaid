## 谁开发了 Bills Must Be Paid？

[Rike Games](https://rikegames.com/) 是总部位于德国法兰克福的两人体制独立工作室。据其[官方新闻资料包](https://rikegames.com/press/bills-must-be-paid/)，团队自 2019 年起发行手游、2024 年起发布网页游戏，全系列累计超过 **50 万次移动下载** 和 **2000 万次网页游玩**。Bills Must Be Paid 是工作室最新的增量类作品——Steam 页面将其定位为「主动增量游戏」，而非挂机类。

## 核心循环：砸、赚、付、升

每一局都遵循同样的压力节奏：

1. **砸存钱罐** — 用鼠标移动锤子，悬停时自动挥击，每次挥击消耗体力。
2. **收集战利品** — 砸碎的猪掉落硬币和随机物品。不同猪型回报不同，有的还能恢复体力。
3. **按时付账单** — 周期性账单带截止日期。付清后从 **三张增益卡中选一张**（如 Deep Freeze、Recovery Smash、Interest Rate）。若拖欠，催收员会对收入抽成（官方材料未公布固定百分比）。
4. **投入剩余硬币** — 购买 [技能树](/wiki/skill-tree 'Bills Must Be Paid 技能树指南') 节点或新 [锤子](/wiki/hammers 'Bills Must Be Paid 锤子升级')。宣布破产后，进度可转化为传承点数，用于永久戒指和手镯。

itch.io 玩家给出 **4.5/5**、CrazyGames 评分 **9.5/10** —— 短局内有真实决策，而非后台挂机。

## 为什么不是挂机游戏？

挂机游戏可以离线推进。Bills Must Be Paid 每一秒都需要你参与：

- **体力有限** — 无法无限砸下去，要判断哪个 [存钱罐](/wiki/piggy-banks '存钱罐类型与掉落') 值得挥锤。
- **账单逼你做决定** — 囤硬币看似安全，一旦错过截止日期，催收员会对所有收入抽成。
- **增益改变下一局** — 付账单不只是生存，更是构筑选择。

Rike Games 称之为「主动增量」。更接近增量 Roguelite：每局通过升级、收集和（Steam 版）破产转生循环，为下一局铺路。

## 存钱罐、锤子与长期目标

### 存钱罐类型

官方描述强调行为差异，而非单纯换皮：

| 猪型            | 玩家体感                        |
| --------------- | ------------------------------- |
| **Normalito**   | 慢而可预测 — 稳定的基础目标     |
| **The Tourist** | 体型大、懒得动，砸碎后恢复体力  |
| **Woody**       | 几乎不动 — 好打但紧迫感低       |
| **Piñata**      | 掉落随机：一枚或一整堆硬币      |
| **El Loco**     | 游荡、折返、冲锋 — 高风险高回报 |

更稀有的类型随进度解锁。Piggies 图鉴记录你遇到过的每一种猪，是保持新鲜感的长线收集目标。

### 锤子与技能树

每把锤子在伤害、挥击速度、暴击率和攻击范围上各不相同。有的范围小但伤害高；有的挥击快、范围大但单次伤害低。技能树分支包括握力、咖啡因成瘾、健身房训练、手腕强化、幸运值，以及落石雨、电击锤子等后期节点。

Steam 完整版在此基础上增加 **27 个成就**、稀有硬币收集、戒指、手镯、桌面小工具和风险机制。
